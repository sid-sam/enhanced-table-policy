Enhanced Table — Privacy Policy

Last updated: 9 October 2026

Enhanced Table is a Forge app that adds an interactive table macro to Confluence Cloud. This page explains what data the app does — and does not — collect.

Data collection

Enhanced Table collects no personal data and has no backend — there is no server, database, or resolver function anywhere in the app. Every feature (search, sort, filter, pagination, CSV export) runs entirely as JavaScript inside the reader's browser, operating only on the table content already present on the Confluence page they're viewing.

Nothing is sent to us, to Atlassian beyond what Confluence itself already handles, or to any third party. The app stores no data of its own — not in Forge's storage APIs, not in cookies, not in any external service.

Permissions

The app's Forge manifest requests one content permission, styles: unsafe-inline, which allows the Atlaskit design components the app renders with to apply their styles correctly. It does not grant access to page content, user data, or any Atlassian API beyond what's needed to render the macro itself.

Changes to this policy

If this app's data practices ever change, this page will be updated and the "Last updated" date above will reflect that.
